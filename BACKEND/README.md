 SLUBT Labs Backend & Analytics

This folder contains the backend services and web-based analytics dashboard for SLUBT Labs.


## Overview

The backend is responsible for:
- Storing experiment data
- Managing user authentication
- Providing analytics for instructors
- Supporting communication between VR app and database

---

##  Features

- User authentication system
- Cloud database integration
- Real-time data storage
- Experiment result tracking
- Web-based analytics dashboard

---

## Tech Stack

- **Firebase** or **MongoDB**
- JavaScript (Node.js optional)
- HTML / CSS / JavaScript (Dashboard)
