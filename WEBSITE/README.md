#  SLUBT Labs Website & Analytics

This folder contains the web-based analytics dashboard and backend services that power the SLUBT Labs ecosystem.

##  Overview
The Website serves as the central hub for instructors and researchers to:
- **Monitor** real-time data coming from the VR simulation.
- **Manage** user authentication and experiment sessions.
- **Analyze** experiment results through a custom dashboard.

---

## Features
- **Instructor Dashboard:** View aggregated experiment data.
- **Cloud Integration:** Real-time synchronization with the VR client.
- **User Management:** Secure login for students and faculty.
- **Data Export:** Tools to download experiment results for further research.

---

##  Tech Stack
- **Database:** Firebase / MongoDB (Real-time data storage)
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Node.js (Optional / Cloud Functions)
