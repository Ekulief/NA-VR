# SLUBT-Labs-Virtual-Reality-IT-Project

A Virtual Reality-Based Psychology Laboratory for Student Experiment Simulation
An IT Project 1 developed to enhance experimental psychology education through immersive Virtual Reality (VR)


##  Overview
SLUBT Labs is a Virtual Reality-based experimental psychology platform designed to simulate laboratory experiments for undergraduate students. The system integrates immersive VR environments, psychological principles, and data analytics to create engaging, interactive, and scientifically valid learning experiences.

This project addresses the limitations of traditional psychology laboratories by providing:

Immersive simulations

Flexible experiment design

Real-time data tracking

Enhanced student engagement



## Objectives

Develop a VR-based platform for simulating psychology experiments

Integrate Human-Computer Interaction (HCI) and psychological learning theories

Provide a web-based analytics dashboard for instructors

Improve student engagement, immersion, and learning outcomes

Ensure scalability and compatibility with VR devices (e.g., Meta Quest)



## Features
# Student Features

Participate in VR-based experiments

Interact with 3D stimuli

Perform tasks (reaction time, memory, attention, etc.)

View personal performance data

 # Instructor Features

Configure experiment variables

Monitor student progress

Access analytics dashboard

Export experiment results

## Psychological Modules

Perception (e.g., visual illusions)

Reaction Time

Attention (Stroop Effect)

Memory (recall & recognition)

Emotion (affective scenarios)

Social Interaction (multiplayer VR)
