#  SLUBT Labs Frontend (VR Application)

This folder contains the **Virtual Reality (VR) application** for SLUBT Labs, developed using Unity and C#.

---

##  Overview

The frontend is responsible for:
- Rendering immersive 3D environments
- Handling user interactions in VR
- Running psychological experiments
- Collecting real-time experiment data

---

##  Features

- Immersive VR laboratory environment
- Interactive psychological experiments:
  - Perception (visual illusions)
  - Reaction Time tasks
  - Attention (Stroop Effect)
  - Memory tests
  - Emotion simulations
  - Social interaction (multiplayer)
- Real-time data logging
- Variable manipulation (stimulus timing, intensity, etc.)

---

## Tech Stack

- **Unity Engine**
- **C#**
- XR Interaction Toolkit (tenntative)
- VR SDK (Meta Quest / OpenXR) (Tentative)
